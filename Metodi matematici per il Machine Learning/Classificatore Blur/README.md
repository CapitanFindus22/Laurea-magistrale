# Classificatore Blur

Classificazione del tipo di sfocatura applicata alle immagini tramite CNN.

## File

- `cnn.m` - Definizione, training e salvataggio CNN.
- `presentazione.mlx` - Presentazione del progetto.
- `final.mat` - Modello migliore ottenuto.

Nella cartella `Dataset` è presente lo script con cui creare il dataset partendo da un insieme di immagini.
